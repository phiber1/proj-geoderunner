GEODE RUNNER - a digging platformer for the TRS-80 MC-10
AN ABENE GAME

Needs: an MC-10 with the 8K internal RAM mod and an MCX32-SD (or the VMC10
for Linux emulator, run with --8k --mcx32sd).

Copy GEODE.BIN and LEVELS.DAT to the SD card, then type

    RUNM"GEODE"

A and S walk, W and Z climb, SPACE digs (with A or S held: that side);
BREAK gives up a level.  A PI-KEY10's joystick 1 works too.  Collect
every geode, then climb the exit ladder out.  150 levels.

geoderunner.pdf has the rules.  Source: https://github.com/phiber1/proj-geoderunner
Public domain (Unlicense).
